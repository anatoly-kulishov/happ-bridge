Установка Happ Bridge (без подписи Apple)
=============================================

1. Скачайте .dmg и откройте диск (двойной клик по файлу).
2. Запустите «Install Happ Bridge.command» → «Установить».
   Приложение попадёт в «Программы».

Если macOS блокирует УСТАНОВЩИК - в Терминале (диск из шага 1 должен быть открыт):

if [ ! -d "/Volumes/Happ Bridge" ]; then
  echo "Диск «Happ Bridge» не открыт. Сделайте двойной клик по файлу .dmg в Загрузках, дождитесь диска и повторите."
  exit 1
fi
xattr -cr "/Volumes/Happ Bridge/Install Happ Bridge.command"
open "/Volumes/Happ Bridge/Install Happ Bridge.command"

Если приложение УЖЕ установлено, но не запускается - в Терминале:

if [ ! -d "/Applications/Happ Bridge.app" ]; then
  echo "Приложение не установлено. Сначала выполните Install Happ Bridge.command."
  exit 1
fi
xattr -cr "/Applications/Happ Bridge.app"
open "/Applications/Happ Bridge.app"

Иконка появится в строке меню (справа вверху), не в Dock.

В настройках можно вручную прописать 127.0.0.1 в Cursor / WebStorm / Firefox
и согласиться на перезапуск приложений.
