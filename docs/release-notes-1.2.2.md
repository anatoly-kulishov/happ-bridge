## Happ Bridge 1.2.2

### Install
1. Download **Happ Bridge-1.2.2-arm64.dmg**
2. Open **Install Happ Bridge.command** → Install

Or wait for the in-app updater if you already have 1.2.0+.

### Fixed
- Footer layout исправлен — «Мастер» слева, «Сохранить» справа, версия по центру
- Убран лишний значок экспорта из header настроек — всё доступно через «Скопировать отчёт» в блоке диагностики
- Блок «Пароль Happ (LAN)» теперь сворачиваемый аккордеон — не мешает если пароль не нужен
- «Скопировать отчёт» теперь копирует полное состояние в JSON (версия, сеть, настройки, SSID, диагностика) — удобно для отправки в поддержку
