## Happ Bridge 1.2.8

### Install
1. Download **Happ-Bridge-1.2.8-arm64.dmg**
2. Open **Install Happ Bridge.command** → Install

If 1.2.6/1.2.7 уже скачали обновление, но версия не сменилась - поставьте этот .dmg один раз вручную. Дальше кнопка «Установить» в настройках.
