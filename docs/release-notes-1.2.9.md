## Happ Bridge 1.2.9

### Install
1. Download **Happ-Bridge-1.2.9-arm64.dmg**
2. Open **Install Happ Bridge.command** → Install

Если установлена 1.2.7/1.2.8 — обновление поставится кнопкой «Установить» в настройках (`latest-mac.yml`). Иначе поставьте `.dmg` вручную один раз.

### Added
- **Тёмная тема на дизайн-токенах** (`--hb-*`): единая палитра, радиусы/тени, системные шрифты (SF Pro Text), `color-scheme: dark`
- **Защита от потери данных**: при закрытии окна с несохранёнными настройками Happ Bridge просит подтверждение
- **Глубокая диагностика подключения** в `main.log`:
  - relay: старт/останов, смена target-IP, установленные pipe
  - ошибки и таймауты переадресации к телефону с err-кодом (`ECONNREFUSED`/`ETIMEDOUT`/…) — видно, где именно рвётся мост
  - первый ответ от телефона (доказательство живости)
  - восстановление после «Связь нестабильна» → «Подключено»
  - слияние повторных вызовов connect (abort in-flight)
  - discovery: устаревшие/не-маршрутизируемые preferred-IP и длительность свипа

### Changed
- **Контраст**: мелкий текст и подписи подняты до читабельности; disabled-кнопки больше не «залипают» почти невидимыми (убрана `opacity-50`)
- **Анти-скачки вёрстки**: стабильная раскладка при загрузке, поиске и прописке приложений
- **Лог прописки приложений**: построчно, с бейджами `OK` / `Ошибка` / `Внимание` — тексты выровнены, ничего не слипается
- Обновлены иконки (`icon.png` + исходник `icon.svg`), favicon/logo, `theme-color`/`color-scheme` мета
