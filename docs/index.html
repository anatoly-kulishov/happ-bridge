macOS · Happ · SOCKS5 / HTTP

Стабильный прокси к Happ на телефоне

Happ Bridge - приложение в строке меню. Один раз укажите 127.0.0.1:10808 и 127.0.0.1:10809 в Telegram, Cursor, Firefox или WebStorm. Когда IP телефона меняется, мост обновляется сам.

GitHub репозиторий Установка

Адреса не меняются

Приложения всегда ходят на localhost. IP телефона живёт только внутри Happ Bridge.

Автопоиск в Wi‑Fi

Находит Happ с открытым LAN-портом, запоминает IP и переподключается при обрыве.

Безопасный localhost

Слушает только 127.0.0.1 - прокси не открыт соседям по сети.

Happ Bridge for macOS

Menu bar utility: stable SOCKS5/HTTP localhost bridge to Happ on your phone. Stop editing proxy IPs after every Wi‑Fi lease change.
