Стабильный прокси к Happ на телефоне

Happ Bridge - приложение в строке меню. Один раз укажите 127.0.0.1:10808 и 127.0.0.1:10809 в Telegram, Cursor, Firefox или WebStorm. Когда IP телефона меняется, мост обновляется сам.

Скачать .dmg (1.1.0) Как установить

Без подписи Apple: откройте DMG → Install Happ Bridge.command → Установить. Установщик сам снимет блокировку с приложения.

Если macOS блокирует установщик

Откройте «Терминал» и выполните (скопируйте обе строки): 

xattr -cr "/Volumes/Happ Bridge/Install Happ Bridge.command"
open "/Volumes/Happ Bridge/Install Happ Bridge.command"

Адреса не меняются

Приложения всегда ходят на localhost. IP телефона живёт только внутри Happ Bridge.

Несколько телефонов

Находит все Happ в сети - выберите нужный IP в списке.

Прописка вручную

Cursor, WebStorm, Firefox - кнопка «Прописать» и предложение перезапустить приложение. Без автоподмены в фоне.

Безопасный localhost

Слушает только 127.0.0.1 - прокси не открыт соседям по сети.
