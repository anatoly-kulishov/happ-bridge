Что делает приложение

Relay только на localhost. Системный proxy macOS не трогаем. Прописка в приложения - только по вашей кнопке. Опциональный логин/пароль Happ LAN (пароль в Keychain) снижает риск подмены SOCKS в Wi‑Fi; чужие сети без пароля помечаются предупреждением.

  • Адреса не меняются

    Приложения всегда ходят на 127.0.0.1. IP телефона живёт только внутри моста.

  • Несколько телефонов

    Находит все Happ в сети - выберите нужный IP в списке.

  • Прописка вручную

    Cursor, WebStorm, Firefox: «Прописать» и предложение перезапустить.

  • Пароль LAN · Keychain

    Те же логин/пароль, что в Happ. Поиск проверяет SOCKS5 auth; чужой открытый SOCKS не подставится. Пароль хранится в Keychain macOS, не в settings.json. Мост Wi‑Fi не шифрует - это делает Happ.

  • Домашние сети

    Отметьте SSID как домашний в настройках - предупреждение о чужой сети пропадёт. Выбранный телефон запоминается отдельно для каждой Wi‑Fi сети.

  • Только localhost

    Слушает 127.0.0.1 - соседи по Wi‑Fi ваш Mac-прокси не видят.

Установка

Сборка без подписи Apple. Установщик кладёт приложение в «Программы». Чтобы снять блокировку Gatekeeper и запустить - одна команда ниже.

1. Установить

  1. Скачайте .dmg с GitHub Releases
  2. Откройте диск и запустите Install Happ Bridge.command
  3. Нажмите «Установить»

Если сам установщик не открывается - сначала скрипт из блока 2.

2. Если блокирует установщик

Вставьте в «Терминал» и нажмите Return:

Terminal 
xattr -cr "/Volumes/Happ Bridge/Install Happ Bridge.command" && open "/Volumes/Happ Bridge/Install Happ Bridge.command"

3. Запустить приложение

После установки, если macOS не даёт открыть Happ Bridge - этот скрипт снимает quarantine и запускает:

Terminal 
xattr -cr "/Applications/Happ Bridge.app" && open "/Applications/Happ Bridge.app"

Иконка появится в строке меню (справа вверху), не в Dock.
