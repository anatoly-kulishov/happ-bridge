Стабильный прокси к телефону

Один раз укажите 127.0.0.1 в Telegram, Cursor, Firefox или WebStorm. Happ Bridge находит Happ в Wi‑Fi и держит мост, даже когда IP телефона меняется.

Что делает приложение

Relay только на localhost. Системный proxy macOS не трогаем. Прописка в приложения - только по вашей кнопке.

  • Адреса не меняются

    Приложения всегда ходят на 127.0.0.1. IP телефона живёт только внутри моста.

  • Несколько телефонов

    Находит все Happ в сети - выберите нужный IP в списке.

  • Прописка вручную

    Cursor, WebStorm, Firefox: «Прописать» и предложение перезапустить.

  • Только localhost

    Слушает 127.0.0.1 - соседи по Wi‑Fi ваш прокси не видят.

Установка

Сборка без Apple Developer ID. Установщик копирует приложение в «Программы» и снимает quarantine Gatekeeper.

Шаги

  1. Скачайте .dmg с GitHub Releases
  2. Откройте Install Happ Bridge.command
  3. Нажмите «Установить»
  4. Разрешите доступ к локальной сети, если спросит

Если macOS блокирует установщик

В Терминале выполните обе строки:

xattr -cr "/Volumes/Happ Bridge/Install Happ Bridge.command"
open "/Volumes/Happ Bridge/Install Happ Bridge.command"
