## Happ Bridge 1.1.9

Visible auto-update download progress.

### Install
1. Download **Happ Bridge-1.1.9-arm64.dmg**
2. Open **Install Happ Bridge.command** → Install

Or wait for the in-app updater if you already have 1.1.8+ (after this build is published).

### Fixed
- **Download progress** — spinner, percent and progress bar while an update is downloading; no more silent «Скачиваем…» that looked stuck
- Download completion / errors are reported again (listener was dropped too early in 1.1.8 and earlier)
