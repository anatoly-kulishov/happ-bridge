## Happ Bridge 1.4.0

### Install
1. Download **Happ-Bridge-1.4.0-arm64.dmg**
2. Open **Install Happ Bridge.command** → Install

Уже установлено приложение? На диске есть **Запустить Happ Bridge.command** — двойной клик
снимет quarantine и запустит установленную копию без переустановки.

### Added
- **Fail-open локальный прокси**: порты `127.0.0.1:10808/10809` слушают всё время работы приложения.
  Если телефон не найден или Happ молчит, SOCKS5 (и HTTP `CONNECT`) обслуживаются напрямую сетью Mac —
  терминал, IDE и CLI больше не получают `ECONNREFUSED`.
- **Codex CLI**: обёртка `codex()` в `~/.bash_profile` — прокси получает только `codex`
  (git/brew/npm/opencode/curl идут напрямую). Обёртка проверяет порт: при выключенном мосте
  codex запускается без прокси, а не с мёртвым адресом.
- **Реестр приложений**: Cursor / WebStorm / Firefox / Codex CLI в одном списке, добавление нового
  приложения — одна карточка в `INJECT_APPS`.
- **Ручной IP**: кнопки «Проверить» (Happ реально отвечает?) и «Подставить везде» (закрепить адрес и подключиться).
- **Диагностика**: цепочка от ближнего к дальнему — Локальные порты, Codex CLI, Приложения, Wi‑Fi/сеть,
  Телефон (TCP), Happ (SOCKS5), сквозная проверка. У ошибок есть кнопки «Повторить» и «Найти телефон».
- **DMG**: файл «Запустить Happ Bridge.command»; установщик предлагает запустить уже установленную копию
  или переустановить.

### Changed
- Диагностика точнее: TCP-проверка телефона отделена от SOCKS-рукопожатия, убрана строка-заглушка «Пароль LAN».
- Скан сети в статус-бадже показывает проценты вместо `done/total`.
- Убраны «шпаргалки» для приложений (Telegram / Cursor / IDE).

### Fixed
- **Codex CLI**: `HTTP(S)_PROXY=http://…` ломал websocket и загрузку моделей — теперь везде `socks5://`.
- Ошибка «Happ не отвечает» больше не появляется для адреса, где вообще никто не слушает.
- `manualIp`, полученный кнопкой «Подставить везде», больше не теряется при следующем сохранении настроек.

### Removed
- Системный SOCKS-прокси macOS (`networksetup`) — функция удалена вместе с UI и авто-откатом.
